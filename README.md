## Overview

Redshift is a biased GPU renderer designed for handling massive production scenes, using acceleration techniques — irradiance caching, photon mapping, and bucket rendering — for fast iteration on complex shots.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Redshift** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **GPU Acceleration** | Multi-GPU rendering with CUDA and Metal support for maximum speed |
| **Biased GI** | Irradiance cache and photon mapping for fast global illumination |
| **AOV Outputs** | Up to 50 arbitrary output variable buffers for compositing |
| **Procedural Shading** | Node-based shader graph with 200+ shading nodes |
